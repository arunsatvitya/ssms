เริ่มต้นใช้งาน (ทุกสิทธิ์)
1
เข้าสู่ระบบ

เปิดลิงก์ระบบที่แจกให้ ใส่ชื่อผู้ใช้และรหัสผ่าน แล้วกดเข้าสู่ระบบ ถ้าเป็นการใช้งานครั้งแรกของโรงเรียน ให้ใช้บัญชีผู้ดูแลระบบที่แอดมินจัดเตรียมไว้

2
รู้จักหน้าจอหลักของระบบ

เมนูด้านซ้ายเป็นทางเข้าทุกหน้า ส่วนด้านบนแสดงวันที่และปุ่มรีเฟรช ส่วนล่างเป็นเมนูย่อสำหรับมือถือ ตัวเลขบนแดชบอร์ดสรุปข้อมูลของวันนี้ทั้งหมด

3
สิทธิ์แต่ละบทบาทมองเห็นอะไรบ้าง

เมนูจะถูกซ่อนอัตโนมัติตามสิทธิ์ที่ได้รับ แต่ถ้าเปิดหน้าไม่ได้จะขึ้นข้อความแจ้งเตือนว่าไม่มีสิทธิ์

บทบาทหน้าที่หลักเมนูที่เห็น
ผู้ดูแลระบบ (แอดมิน)ดูแลข้อมูลนักเรียน ครู ห้องเรียน ตั้งค่าระบบ และสิทธิ์ทั้งหมดทุกเมนู
เจ้าหน้าที่เช็คชื่อเช็คชื่อ 3 รอบ ติดตามห้องที่ยังไม่เช็ค ดูโดดเรียน ดูสถิติเช็คชื่อ · ติดตาม · โดดเรียน · สถิติ · แดชบอร์ด
เจ้าหน้าที่ประกาศทำได้ทุกอย่างของเจ้าหน้าที่เช็คชื่อ และสร้างประกาศบนจอมอนิเตอร์ของเจ้าหน้าที่เช็คชื่อ · ประกาศข่าวสาร
ครู / บุคลากรเช็คชื่อได้ทุกห้อง บันทึกการลาของตัวเอง ดูสถิติและจอมอนิเตอร์เช็คชื่อ · สถิติ · การลาครู · จอมอนิเตอร์
ผู้ดูแลจอมอนิเตอร์เปิดหน้าจอแสดงผลบนไฟล์แนวตั้งในโรงเรียน โดยไม่ต้องล็อกอินจอมอนิเตอร์ · ประกาศข่าวสาร · แดชบอร์ด
ต้องการเปลี่ยนสิทธิ์ของใคร ให้แอดมินแก้ที่หน้า ครู / บุคลากร (ช่อง “สิทธิ์การใช้งาน”) หรือหน้า ตั้งค่าระบบ
4
ข้อควรรู้เรื่องระบบ 2 ห้องเรียน

โรงเรียนนี้มีห้องเรียน 2 ระบบที่แยกจากกัน ไม่ต้องผูกกัน

  • ห้องเรียนศาสนา — ใช้ในรอบที่ 2 (เช็คชื่อวิชาศาสนา) แสดงชื่อภาษามลายูยาวี
  • ห้องเรียนสามัญ — ใช้ในรอบที่ 3 (เช็คชื่อวิชาสามัญ) แสดงชื่อภาษาไทย
  • รอบที่ 1 (เช็คชื่อในแถว) — แอดมินเลือกได้ว่าจะเข้าแถวตามห้องศาสนาหรือห้องสามัญ ที่เมนู ตั้งค่าระบบ
  • ห้อง “ไม่เรียน” (ระดับชั้น “ไม่มี”) — เป็นห้องสำหรับนักเรียนที่เรียนเฉพาะวิชาศาสนา ห้องนี้จะไม่ปรากฏในการเช็คชื่อวิชาสามัญและไม่ถูกนับในสถิติ
ผู้ดูแลระบบ (แอดมิน)
1
ตั้งค่าข้อมูลโรงเรียนและระบบเช็คชื่อ

ไปที่เมนู ตั้งค่าระบบ กรอกชื่อโรงเรียน ปีการศึกษา ภาคเรียน ระดับชั้นที่ใช้ และเลือกว่า รอบที่ 1 (เช็คชื่อในแถว) จะเข้าแถวตามห้องศาสนาหรือห้องสามัญ จากนั้นกดบันทึก

2
เพิ่มนักเรียน (เพิ่มทีละคน หรือนำเข้าไฟล์ Excel)

ไปที่เมนู นักเรียน กด เพิ่มนักเรียน เพื่อกรอกทีละคน หรือกด นำเข้า Excel เมื่อมีไฟล์ ส.ช. ของโรงเรียน ในขั้นตอนนำเข้า ระบบจะให้เลือกคอลัมน์ที่ต้องการนำเข้า และเลือกแถวหัวตาราง ถ้าไม่เลือกคอลัมน์ ระบบจะไม่เขียนทับข้อมูลเดิม

3
จัดการห้องเรียน (รวมห้อง “ไม่เรียน”)

ไปที่เมนู ห้องเรียน แล้วกดเพิ่มห้องเรียน ระบบแยกห้องเป็น 3 ประเภท

  • ศาสนา — ห้องเรียนวิชาศาสนา ใช้ในรอบที่ 2
  • สามัญ — ห้องเรียนวิชาสามัญ ใช้ในรอบที่ 3
  • ประจำชั้น — ห้องประจำชั้นของนักเรียน

ห้องสำหรับนักเรียนที่เรียนเฉพาะวิชาศาสนา ให้สร้างเป็นประเภท สามัญ ชื่อ ไม่เรียน และระดับชั้น ไม่มี ระบบจะเอาห้องนี้ออกจากการเช็คชื่อวิชาสามัญและจากสถิติให้อัตโนมัติ

4
จัดการครู / บุคลากรและบัญชีผู้ใช้

หน้า ครู / บุคลากร เป็นทั้งรายชื่อบุคลากรและบัญชีผู้ใช้ของระบบ ถ้ากรอก “ชื่อผู้ใช้” และ “รหัสผ่าน” ระบบจะสร้างบัญชีให้อัตโนมัติ และเลือก “สิทธิ์การใช้งาน” เป็น แอดมิน / เจ้าหน้าที่เช็คชื่อ / เจ้าหน้าที่ประกาศ / ครู / ผู้ดูแลจอมอนิเตอร์ ได้ตามต้องการ

  • กด ลบ จะเป็นการ “ระงับบัญชี” ไม่ได้ลบข้อมูลบุคลากรออกจากระบบ
  • รหัสผ่านต้องมีอย่างน้อย 6 ตัวอักษร ถ้าไม่กรอกรหัสผ่าน ระบบจะไม่สร้างบัญชี
5
ประกาศข่าวสารขึ้นจอมอนิเตอร์

ไปที่เมนู ประกาศข่าวสาร กด สร้างประกาศ ใส่หัวข้อ ข้อความ เลือกเทมเพลตและภาพเคลื่อนไหว แล้วกด เผยแพร่ ข้อความจะขึ้นจอมอนิเตอร์ทันที

6
รายงานสรุปและบันทึกการใช้งาน
  • รายงานสรุป — ดูกราฟเปรียบเทียบวิชาศาสนา/สามัญ และส่งออกเป็น Excel
  • บันทึกการใช้งาน — ดูประวัติว่าใครแก้ไขหรือลบข้อมูลอะไรบ้าง (Audit Log) ควรเปิดดูเมื่อมีข้อสงสัย
เจ้าหน้าที่เช็คชื่อ
1
เช็คชื่อ 3 ขั้นตอน

หน้า เช็คชื่อ แบ่งเป็น 3 ขั้น เพื่อไม่ให้สับสน คลิกไปที่ขั้นถัดไปเมื่อทำขั้นก่อนหน้าเสร็จแล้วเท่านั้น

  • ขั้นที่ 1 — เลือกวันที่ แล้วกดประเภทการเช็คชื่อ (รอบ 1 ในแถว / รอบ 2 วิชาศาสนา / รอบ 3 วิชาสามัญ) ปุ่มที่เลือกไว้จะถูกไฮไลต์ไว้ กดรอบที่เดิมซ้ำก็ได้ ระบบจะเริ่มใหม่เสมอ
  • ขั้นที่ 2 — เลือกห้องเรียน (ระบบแสดงเฉพาะห้องของระบบที่เลือกไว้)
  • ขั้นที่ 3 — รายชื่อนักเรียนพร้อมปุ่มสถานะ กดเลือกทีละคน หรือใช้ “เลือกทั้งหมด = มาเรียน” แล้วกด บันทึกข้อมูล
2
ติดตามว่าห้องไหนยังไม่ได้เช็คชื่อ

หน้า ติดตามการเช็คชื่อ แสดงสรุปแต่ละรอบของวันที่เลือก พร้อมสถานะ “เช็คครบแล้ว / เช็คยังไม่ครบ / ยังไม่ได้เช็ค” เพื่อให้เจ้าหน้าที่ไล่ทีละห้องจนครบทุกรอบ

3
ตรวจโดดเรียน / ผิดปกติ

หน้า โดดเรียน / ผิดปกติ ค้นหานักเรียนที่ไม่มีการเช็คชื่อ ณ วันที่ที่เลือก (ค่าเริ่มต้นคือวันนี้) แล้วกด ยืนยัน ได้เลยว่าเป็นการโดดเรียนจริง หรือแก้ไขข้อมูลได้ถ้าบันทึกผิด

4
สถิติการมาเรียนและพิมพ์ A4

หน้า สถิติการมาเรียน เลือกช่วงวันที่ (ปุ่มลัด “วันนี้” และ “30 วัน”) แล้วกด แสดงสถิติ จะได้ 3 ตาราง

  • สรุปรายวัน — ตารางแรก พร้อมการ์ดสรุปด้านบน
  • วิชาศาสนา — เรียงทุกห้องตามช่วงชั้น (อนุบาล / ประถมศึกษา / มัธยมศึกษา) มีแถว “รวมระดับชั้น” และ “รวมทั้งหมด”
  • วิชาสามัญ — เรียงทุกห้องตามช่วงชั้น (อนุบาล / ประถมศึกษา / มัธยมต้น / มัธยมปลาย) ห้อง “ไม่เรียน” จะไม่ปรากฏ

เมื่อกด พิมพ์ A4 ระบบจะจัดหน้าพิมพ์ให้แต่ละตารางอยู่คนละหน้า (หน้ารายวัน / หน้าวิชาศาสนา / หน้าวิชาสามัญ) ในรูปแบบเอกสารราชการทั่วไป ตารางสีดำ ไม่มีกรอบสีประดับ

เจ้าหน้าที่ประกาศ
1
ทำได้ทุกอย่างเหมือนเจ้าหน้าที่เช็คชื่อ

เจ้าหน้าที่ประกาศมีสิทธิ์เช็คชื่อครบถ้วนเหมือนเจ้าหน้าที่เช็คชื่อ คือ เช็คชื่อ 3 รอบ, ติดตามการเช็คชื่อ, ตรวจโดดเรียน และดูสถิติการมาเรียน

ดูวิธีทำงานแต่ละหน้าที่ในหัวข้อ เจ้าหน้าที่เช็คชื่อ ได้เลย ขั้นตอนเหมือนกันทุกประการ
2
สร้างประกาศขึ้นจอมอนิเตอร์

ไปที่เมนู ประกาศข่าวสาร กด สร้างประกาศ แล้วกรอก

  • หัวข้อประกาศ — ข้อความบรรทัดแรกที่เห็นบนจอ
  • ข้อความ — รายละเอียดที่แสดงหมุนเวียนบนจอ
  • เทมเพลต — เลือกสีและรูปแบบของจอ รวมถึงแบบภาษามลายู
  • ชนิดภาพเคลื่อนไหว — เลือกวิธีแสดงผล เช่น เลื่อน ซูม หรือไฟวิบ

กด บันทึก เพื่อเก็บร่าง หรือกด เผยแพร่ เพื่อส่งขึ้นจอทันที ประกาศที่เผยแพร่แล้วแก้ไขได้ และประกาศเก่าจะถูกแทนที่

3
ดูผลบนจอมอนิเตอร์ได้ทันที

เปิดหน้า จอมอนิเตอร์ ในเมนู หรือเปิดลิงก์จอพร้อมรหัสเข้าถึงบนจอประจำห้อง จอจะหมุนสลับระหว่าง รายงานนักเรียน / การลา / ประกาศ ตามเวลาที่ตั้งไว้ในหน้าตั้งค่าระบบ

ครู / บุคลากร
1
เช็คชื่อได้ทุกห้องเรียน

ครูทุกคนมีสิทธิ์เช็คชื่อได้ทุกห้อง ไม่จำเป็นต้องเป็นห้องประจำของตัวเอง ทำตาม 3 ขั้นตอนเดียวกับเจ้าหน้าที่เช็คชื่อ

  • รอบที่ 1 (ในแถว) — เข้าแถวตามระบบห้องที่แอดมินตั้งไว้
  • รอบที่ 2 — ห้องเรียนศาสนา แสดงชื่อภาษามลายูยาวี
  • รอบที่ 3 — ห้องเรียนสามัญ แสดงชื่อภาษาไทย (ห้อง “ไม่เรียน” จะไม่ปรากฏ)
2
บันทึกการลาของตัวเอง

ไปที่เมนู การลาครู กด บันทึกการลา เลือกวันที่ ประเภทการลา (ลาป่วย / ลากิจ / ลาพักผ่อน / ลาคลอด / อื่น ๆ) และใส่หมายเหตุ กดบันทึก การลาของครูจะแสดงบนจอมอนิเตอร์ในหมวด “ครู / บุคลากรลา” ทันที

3
ดูข้อมูลที่เกี่ยวข้องได้
  • สถิติการมาเรียน — ดูสถิติรายห้องและพิมพ์เป็นเอกสาร A4 ได้
  • โดดเรียน / ผิดปกติ — ดูรายชื่อนักเรียนที่ไม่มีการเช็คชื่อ
  • จอมอนิเตอร์ — เปิดดูจอที่ติดตั้งในโรงเรียนได้จากเมนู
  • นักเรียน / ห้องเรียน — ดูข้อมูลได้ แต่แก้ไขข้อมูลหลักไม่ได้ (สิทธิ์นี้สำหรับแอดมิน)
ถ้าเมนูใดไม่ปรากฏ แปลว่าบัญชีนี้ยังไม่ได้รับสิทธิ์นั้น ให้แจ้งแอดมินเพื่อเพิ่มสิทธิ์ให้
ผู้ดูแลจอมอนิเตอร์
1
เปิดจอมอนิเตอร์โดยไม่ต้องล็อกอิน

แอดมินไปที่หน้า ตั้งค่าระบบ คัดลอก “ลิงก์จอมอนิเตอร์” ที่มีรหัสเข้าถึงติดมาด้วย แล้วเปิดลิงก์นั้นบนคอมพิวเตอร์ที่ติดตั้งจอประจำห้อง

  • ลิงก์จะเปิดหน้าจอเต็มจอโดยไม่แสดงเมนู ปุ่มล็อกอิน หรือแถบด้านข้าง
  • รหัสเข้าถึงอยู่ในรูปแบบ ?view=monitor&key=… ให้เก็บลิงก์นี้ไว้และใช้กับทุกจอในโรงเรียน
  • เปลี่ยนรหัสเข้าถึงได้ที่หน้าตั้งค่าระบบ ถ้ามีคนที่ไม่ควรเห็นข้อมูล
2
ปรับแต่ละจอให้เหมาะกับห้อง

ตั้งค่าในหน้าตั้งค่าระบบได้ดังนี้

  • เทมเพลต — สีและรูปแบบของจอ (เช่น แบบโรงเรียน แบบมัดหมี แบบมินิมอล)
  • ระยะเวลาหมุนแต่ละหมวด — นักเรียน / การลา / ประกาศ (วินาที)
  • ช่วงเวลา Polling — ระบบดึงข้อมูลใหม่ทุกกี่วินาที
  • ข้อความท้ายจอ — ข้อความขอบคุณหรือชื่อโรงเรียนที่แสดงด้านล่าง
ควรใช้คอมพิวเตอร์ที่เปิดจอเต็มจอ (Full screen / โหมดเต็มหน้าจอ) และปิดการนอนของเครื่อง เพื่อให้จอแสดงข้อมูลต่อเนื่อง
3
หมวดข้อมูลที่จอแสดง
  • รายงานนักเรียน — นักเรียนโดดเรียน มาสาย และอัตราการเข้าเรียนของวันนี้
  • รายงานการลา — การ์ดครูและบุคลากรที่ลา พร้อมประเภทการลาและหมายเหตุ
  • ประกาศ — ข้อความประกาศหมุนเวียนตามเทมเพลตและภาพเคลื่อนไหวที่เลือก

เมื่อมีการเช็คชื่อหรือบันทึกการลาใหม่ จอจะอัปเดตเองภายในรอบเวลา Polling ไม่ต้องกดรีเฟรช
